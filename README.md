# Python Cyber Learning

Collection de travaux pratiques réalisés pendant mon autoformation en Python, avec une orientation progressive vers les systèmes, Linux et les fondamentaux de la cybersécurité.

> **Contexte :** ces scripts sont des exercices d'apprentissage personnel. Ils ne constituent pas un projet professionnel de cybersécurité.

## Objectifs

- Consolider les bases de Python
- Comprendre l'interaction entre Python et le système d'exploitation
- Manipuler fichiers, processus, threads et archives
- Découvrir progressivement des notions utiles en systèmes et cybersécurité

## Organisation

### `01_os/`
Découverte du module `os` et manipulation du système de fichiers.

### `02_system_commands/`
Premiers essais avec `subprocess` et l'exécution de commandes système.

### `03_threading/`
Découverte des threads et de la journalisation avec `logging`.

### `04_files_and_zip/`
Manipulation de fichiers et d'archives ZIP avec `zipfile`.

### `05_python_modules/`
Exercices autour de modules Python utilisés pendant l'apprentissage.

### `06_security_experiments/`
Expérimentations pédagogiques liées à la sécurité. Tout code de cette section doit être utilisé uniquement sur des systèmes et comptes autorisés.

## Parcours complémentaire

En parallèle de ces exercices, j'ai suivi le parcours **Pre Security** sur TryHackMe afin de découvrir les fondamentaux des systèmes, réseaux, ligne de commande et technologies du Web.

## Technologies / notions

`Python` · `Linux` · `os` · `sys` · `subprocess` · `threading` · `logging` · `zipfile`
