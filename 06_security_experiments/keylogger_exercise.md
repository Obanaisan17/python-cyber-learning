# Keylogger exercise

Ce dossier correspond à un exercice personnel réalisé pendant l'apprentissage de Python autour de `pynput`, `logging` et des événements clavier.

Le script original n'est pas recopié automatiquement dans ce dépôt depuis cette interface. L'exercice doit rester strictement limité à un environnement de test personnel et autorisé.

## Notions étudiées

- import d'un module externe (`pynput`)
- écoute d'événements clavier
- fonctions de callback
- journalisation avec `logging`
- boucle d'écoute

## Contexte d'apprentissage

L'objectif de cet exercice était de comprendre techniquement comment un programme Python peut recevoir des événements clavier et les journaliser. Il ne s'agit pas d'un outil destiné à surveiller d'autres utilisateurs.
