# 06 — Security experiments

## Objectif
Conserver dans un espace clairement identifié les expérimentations de code réalisées pendant l'apprentissage et ayant un lien avec la sécurité informatique.

## Fichier
- `keylogger.py`

## Contexte
Cet exercice est conservé comme travail d'apprentissage et de compréhension technique. Un code de capture de frappes peut être sensible : il doit être exécuté uniquement dans un environnement de test contrôlé, sur ses propres systèmes et avec une autorisation explicite.

## Ce que j'ai appris
L'objectif était de comprendre certaines interactions entre un programme Python et les événements clavier, et non de développer un outil destiné à surveiller des utilisateurs.
